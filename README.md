# AI EVERY DAY — 30 дней практики

Адаптивный сайт-челлендж: 30 практических способов использовать искусственный интеллект в повседневной жизни, работе, творчестве и обучении.

## Возможности

- 30 ежедневных практических заданий.
- Четыре тематические недели.
- Общий и недельный прогресс.
- Сохранение отметок в браузере (`localStorage`).
- Сброс прогресса.
- Адаптивный дизайн для телефона и компьютера.

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `ai-every-day`.
2. Загрузите `index.html`, `styles.css`, `script.js` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Ссылка на сайт появится в разделе Pages.

## Примечание

Отметки прогресса сохраняются локально в браузере и не синхронизируются между устройствами. При использовании AI проверяйте факты и не отправляйте в сервисы конфиденциальные данные.
